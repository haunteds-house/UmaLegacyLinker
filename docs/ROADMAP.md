# Collection planner goals

Version 1.12.0 puts the actual Uma.guide roster viewer first, with a simpler local
plan editor, shared collection filters, exactly one borrowed support slot and
reversible plan removal. Version 1.11.0 practice comparisons remain optional.
Whole-career and race predictions remain development goals.

| Goal | Current behavior | Remaining work |
| --- | --- | --- |
| Recognizable collection | Embedded Uma.guide viewer; offline pictures, names, sorting and aptitude/spark/skill filters | More useful comparison views as performance metrics become available |
| Team Trials replacements | Start from an observed division/style and compare other owned trainees | Forecast an untrained runner's TT score and model interactions within the team |
| Requirements before trainee | Save skills and aptitudes without a trainee; compare owned support effects and practice contributions toward targets | Model complete careers, energy, events and scenario strategy; validate final-stat forecasts |
| Internal resource tools | Skill-point, awakening-material and Grand Concert song budgets; manual balances and earning rates | Full Concert lesson/technique/shop strategy and verified resource acquisition routes |
| Original lineage linker | Visible sidebar entry, original local/remote searches and detailed inspectors; career-plan handoff | Use its inheritance probabilities and affinity scores directly in setup comparison |
| Multi-career goals | Simplified plans, reversible removal, prerequisites, stop conditions and collection checks | Generate parent/grandparent training order, follow new career results and propose the next useful career |
| Competitive race planning | Recorded TT statistics and inherited lineage analysis | TT/CM race simulation, skill-value estimates and uncertainty-aware comparisons |

## Next development step

Expand the practice model into a complete career model: energy and recovery,
practice selection after seeing the board, race schedules/rewards, event
reliability and scenario-specific additions. Collect more comparable exported
previews, including mature friendship stacks, and validate career-level forecasts
against completed runs. Then add TT/CM evaluation and use both models to choose
a training order for missing parents and runners.

The shortlist combines aptitude fit, skill access and estimated practice output
under saved assumptions. It does not establish which setup will win a race or
finish with the best career stats. Manual goal completion remains available.
