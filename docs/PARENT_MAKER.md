# Parent Maker

Parent Maker reverses the normal lineage search. Instead of choosing an Ace first,
you choose the Sparks wanted on the **next parent**. The app then:

1. ranks legal local-local and local-uma.moe parent pairs for the requested Spark package;
2. checks the characters you own and chooses the legal target character with the highest lineage affinity for each shortlisted pair;
3. reports requested-Spark coverage, star support and inheritance/hint percentages;
4. shows remote friend details when one member of the pair came from uma.moe.

Only one remote parent is permitted in a result because a training run can borrow only
one legacy. The two direct parents must also be different characters, regardless of
costume.

## Requested Sparks

The Parent Maker page can target:

- White skill Sparks;
- Scenario Sparks;
- Pink aptitude Sparks;
- Blue stat Sparks;
- Green unique Sparks;
- Race Sparks.

Each request has a **priority** and a **preferred star amount**. Priority controls how
strongly that Spark family affects the pair's Parent Maker score. Preferred stars are
a readiness target for factor types whose value is primarily carried by star quantity.

For intermediate-parent building, Parent Maker treats these Unity skill-hint families
as equivalent sources:

- `Ignited Spirit: Wit` and `Ignited Spirit: Wit+`;
- `Racing Spirit: Stamina` and `Racing Spirit: Stamina+`.

Both members of each pair give the same corresponding skill hint when inherited. The
`+`/non-`+` factor generated by the new trainee depends on the career result, so Parent
Maker does not prefer one source variant over the other at this stage.

## Percentages

For White skill and Scenario targets, the displayed percentage is the chance that the
requested factor source passes its corresponding skill/stat effect during the two
Inspiration events, using Legacy Linker's existing per-star rates and individual
affinity coefficients. Race and Pink factors use their corresponding configured
inheritance-rate model.

These percentages are **not** presented as the probability that the newly trained
parent will generate that Spark at career completion. End-of-career Spark generation
depends on the trainee's career performance and game generation rules that are not
known from the parent pair alone.

## Owned target characters

When an umadump `card_data.json` (or `card_data(1).json`) is beside the selected
trained-character export, Parent Maker uses it to limit target recommendations to
characters actually owned by the player. If that file is unavailable, it falls back
to characters represented in the local veteran export.

Affinity is character-level, so when several owned costumes represent the same
character Parent Maker keeps the highest-talent copy for display and tie-breaking.

## uma.moe

When **Include uma.moe** is enabled, Parent Maker reuses Legacy Linker's existing v3
search client and record normalizer. Requested White skills are sent as soft search
hints where the public API supports them. All returned candidates are then scored
locally against the complete requested Spark package; the remote API is never treated
as the final authority for ranking.

If uma.moe is unavailable, the run continues with local-only results and records the
remote error in `parent_maker_results.json`.
